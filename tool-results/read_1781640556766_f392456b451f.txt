     1→# Project Worklog — VaR Risk Model Web Application
     2→
     3→## Project Overview
     4→Building a comprehensive Value-at-Risk (VaR) risk model as an interactive Next.js web
     5→application. Implements the full methodology stack described in the requirements:
     6→parametric, historical simulation, Monte Carlo, filtered historical simulation, EVT,
     7→Expected Shortfall, backtesting (Kupiec/Christoffersen/Basel traffic light), risk
     8→decomposition (marginal/component/incremental VaR), stress testing, and an interactive
     9→dashboard with multiple visualizations.

    40→Work Log:
    41→- src/lib/var/types.ts — full type system (MarketData, VarResult, BacktestResult, DecompositionResult, StressResult, FullReport).
    42→- src/lib/var/rng.ts — mulberry32 seeded PRNG, Box-Muller normal, Acklam normal inverse CDF, normal CDF, linear-interpolation quantile, mean/std/sum, covariance matrix, Cholesky decomposition (with ridge correction), correlation matrix, histogram (NaN-safe), chi-square p-value via regularized incomplete gamma (series + Lentz continued fraction), downsample.
    43→- src/lib/var/market-data.ts — 7-asset universe (SPX, AAPL, XOM, TLT, EURUSD, GOLD, BTC), correlated GBM simulation with 4 volatility regimes (calm/buildup/crisis/recovery), crisis contagion across asset classes, realized covariance/mean/vol, portfolio weight scaling.
    44→- src/lib/var/methods.ts — parametric (variance-covariance, sqrt-of-time horizon scaling), historical simulation (overlapping horizon returns), Monte Carlo (correlated GBM path stepping, 10k paths, returns sample paths for viz), filtered HS (EWMA vol filter + bootstrap of standardized residuals), EVT (Zhang-Stephens GPD MLE fit + analytic VaR/ES formulas + augmented distribution). Fixed critical bugs: double-applied volatility, operator-precedence NaN in portfolio weights, parametric sample injection pollution, EVT using downsampled data.
    45→- src/lib/var/backtest.ts — rolling-window backtest, Kupiec POF LR test, Christoffersen independence + conditional coverage tests, Basel traffic-light zones (green/yellow/red with capital multipliers).
    46→- src/lib/var/decomposition.ts — marginal VaR (analytic dVaR/dw), component VaR (sums to parametric total), incremental VaR (historical-based, leave-one-out), standalone VaR.
    47→- src/lib/var/stress.ts — 7 scenarios (Lehman 2008, COVID 2020, Rate Shock 2022, equity crash, vol spike, crypto wipeout, flight to safety) with per-asset-class shock factors.
    48→- src/lib/var/engine.ts — orchestrator running all 5 methodologies + backtest + decomposition + stress.
    49→- src/lib/var/cache.ts — memoized market-data cache.
    50→- src/app/api/var/report/route.ts — full report endpoint with query params (confidence, horizon, seed, method, positions, totalValue).
    51→- src/app/api/var/market/route.ts — compact price history for charting.
